# EEG Seizure Detection – Frontend

## 📌 Project Overview
This project is a **frontend user interface** for an **EEG-based epileptic seizure detection system**.  
It is designed to allow users to upload EEG data and view prediction-related information in a simple and user-friendly way.

> ⚠️ Note: This repository contains **frontend code only**.  
> The machine learning backend is maintained separately and is **not deployed here**.

---

## 🖥️ Frontend Features
- Clean and simple UI
- EEG file upload interface
- Input fields for patient details (name, age, etc.)
- Predict button (UI-level interaction)
- Result display section (static / demo output)
